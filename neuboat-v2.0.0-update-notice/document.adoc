== 고객 안내사항

=== 업데이트 전 확인사항

* *[Control 제품]* Engine GW가 반드시 연결된 상태에서 업데이트해야 합니다. 분리된 상태에서는 업데이트가 실패합니다.
* *[Navi 제품]* *Setting > Navi Control* 설정값이 업데이트 후 초기화되므로, 현재 설정을 미리 기록해 두시기 바랍니다.
* *[V1.0.5 사용 고객]* 온라인 업데이트가 불가하며, SD카드로만 업데이트할 수 있습니다. 제품별로 SD카드 패키지가 다르므로, 반드시 해당 제품용 패키지를 사용해 주세요.
* *[공통]* V2.0.0 업데이트 이후 버전 다운그레이드는 SD카드를 통해서만 가능합니다. V2.0.0부터 온라인 업데이트는 버전 업만 가능합니다.

=== 업데이트 중 실패 시

* *[V1.1.5 사용 고객]* 업데이트가 실패하면 실패 화면의 *재시도* 버튼을 눌러 주세요. 2회 재시도 후에도 실패하면 아비커스로 문의해 주세요.

=== 업데이트 후 필수 조치

* *[Control 제품, V1.x → V2.0]* 이미 완료한 항목을 포함하여 SIC(Maneuvering Calibration) 전체를 다시 수행해야 합니다. 이번 버전의 대규모 성능 개선에 따른 조치이며, 이후 업데이트에서는 필요 없도록 개선할 예정입니다.
* *[공통]* Navi Control 설정을 다시 입력해 주세요.

=== GPS 알람 개선

V1.x에서 자주 발생하던 GPS 알람을 알람 정책 변경으로 개선했습니다.

=== NEUBOAT Mobile APP 정식 출시

NEUBOAT Mobile APP이 정식 출시되었습니다.

=== 알려진 이슈

* *[V1.1.5 → V2.0, Control 외 제품]* 업데이트 목록에 Engine GW 항목이 표시되지만, 업데이트 진행에는 영향이 없습니다.

== 미국법인 안내사항 (영업·고객대응)

=== 고객 대응 포인트

* Control 고객에게는 SIC 재수행을 사전에 반드시 공지해야 합니다. 불만이 가장 많이 나올 수 있는 항목이므로, _"이번 한 번만, 성능 개선 때문"_ 이라는 메시지를 함께 전달합니다.
* Engine GW를 제거한 채 운용 중인 Control 고객이 있다면 업데이트 전에 개별 연락합니다.
* 업데이트 후 화면이 다르게 뜬다는 문의가 오면 MFD GW 조치 대상입니다. 별도 가이드가 나올 예정이며, 그 전까지는 본사로 에스컬레이션합니다.
* V2.0.0 업데이트를 안내할 때 NEUBOAT Mobile APP 정식 출시 소식도 함께 전달합니다.

=== V1.0.5 고객: SD카드 업데이트

온라인 업데이트가 불가하며, SD카드로만 업데이트합니다. SD카드 패키지는 NEUBOAT 365 (https://neuboat-admin.avikus.ai/[])에서 다운로드하며, 제품별로 패키지가 다릅니다.

[cols="1,1",options="header"]
|===
| 제품 | SD카드 패키지

| Full Control, Dock Control, Navi Control
| 전체 패키지

| DOCK II, NAVI, Full Assist
| Engine GW 업데이트 파일을 제외한 패키지
|===

WARNING: DOCK II, NAVI, Full Assist 제품군에 전체 패키지를 사용하면 업데이트가 실패합니다. 패키지 구분에 주의해 주세요.

=== V1.1.5 고객: 업데이트 실패 시 (제품 공통)

. 실패 화면의 *재시도* 버튼으로 다시 진행합니다. 대부분 재시도로 해결됩니다.
. 2회 재시도 후에도 실패하면 본사로 에스컬레이션합니다. (트러블슈팅 대상)
