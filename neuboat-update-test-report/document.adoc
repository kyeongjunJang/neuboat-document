. *서비스 상태 확인* - 모듈 정상 실행 여부

판정 기준은 계획서(AVK-UPD-001)의 기준을 따르되, 본 보고서에서 WARN(조건부 PASS) 등급을 추가하여 3단계로 판정한다.

*PASS 조건*

* 모든 컴포넌트가 예상 버전으로 업데이트됨
* 모든 서비스 정상 실행
* DB 마이그레이션 및 파라미터 적용 정상

*WARN 조건 (조건부 PASS)*

* 업데이트 완료 및 서비스 정상 동작하나, 예상과 다른 데이터 손실·마이그레이션 이슈가 확인된 경우
* 확인된 이슈는 <<발견된 이슈>>에 등록하여 별도 관리한다

*FAIL 조건*

* 컴포넌트 버전 미일치 또는 의도되지 않은 Skip 발생
* 서비스 미실행
* 재시도로 복구되지 않는 업데이트 실패 또는 DB 손상

NOTE: WARN 등급은 계획서의 PASS/FAIL 2단계 기준으로는 "업데이트는 정상이나 데이터 이슈가 확인된 회차"를 구분할 수 없어 본 보고서에서 추가한 판정 등급이다.

==== 1.1.x 기인 이슈 및 대응 방안 (Known Issues)

_이미 배포된 1.1.x 버전에서 기인하여 수정 배포가 불가한 항목. 대응 절차로 관리한다._

[cols="1,3,2,3",options="header"]
|===
| 번호 | 내용 | 영향도 | 대응 방안

| KI-1
| 엔진 제조사 설정이 저장된 상태에서 EIU 미연결 구성(Dock2, Navi 등)으로 v1.1.5 → v2.0.0 업데이트 시, v2.0.0 패키지에 포함된 엔진 업데이트 파일로 인해 1.1.5의 EIS가 엔진 게이트웨이 업데이트 실패를 보고하며 진행 불가
| 시험 환경처럼 제품 구성을 변경한 경우에 한정. 단독 제품 실사용에서는 엔진 설정 자체가 불가하여 발생 가능성 낮음
| 엔진 설정 DB 초기화 후 재시도 해야 함. 필요 시 DB 초기화 방법 안내 필요

| KI-2
| Dock2, Navi 등 EIU 미장착 제품의 업데이트 화면 기기 목록에 Engine Gateway 행이 표시됨 — 두 제품 모두에서 확인 (아래 그림 참조)
| 표시상 혼동 유발 (동작 영향 없음)
| 미연결 장치 행이 표시될 수 있음을 안내가 필요

| KI-3
| EIU 연결 구성(Dock2 Control, Navi Control 등)에서 엔진 제조사가 선택되지 않은 상태로 v1.1.5 → v2.0.0 업데이트 시 Engine Gateway 업데이트가 실패하며 진행 불가. v1.1.5의 엔진 설정은 Suzuki 외 제조사의 경우 Others 선택 후 숫자 값 입력이 필요함
| Suzuki 외 엔진 사용 고객은 무엇을 선택·입력해야 업데이트가 가능한지 알기 어려움. 현장에서 Engine GW를 분리한 채 v2.0.0 업데이트 후 재연결하여 엔진 선택 → 재업데이트하는 우회 시도가 예상됨
| Suzuki 외 엔진의 설정 방법(Others 선택 및 입력 값) 안내와, 설정이 어려운 경우의 우회 절차(Engine GW 분리 후 업데이트 → 재연결·엔진 선택 → 재업데이트)를 정리 필요
|===

== 결론 (Test Conclusion)

=== 결론

* *v1.1.3 / v1.1.5 → v2.0.0 마이그레이션*: 전 제품군(6종)에서 최종 목표 버전 도달 및 서비스 정상 동작을 확인하였다. DB 마이그레이션은 svm_ss·sic 정상, sdm·apg에서 일부 항목의 이관 누락(&#35;1, &#35;2)을 확인하였다.
* *v2.0.0 → v2.0.1 (개선된 업데이트 기능)*: 전 제품군에서 SD 카드 / 온라인 / 모바일 업데이트 정상 동작을 확인하였다. Navi Control 1회차에서 ORU 이상(&#35;4)이 발생하였으나 재부팅 후 정상 완료되었다.
* *실패 후 재시도 및 버전 정합성*: 예외 시험 4개 조합 모두 재시도를 통해 목표 버전 일치 복구를 확인하였다. 실사용 조건에서 발생한 ORU-MFD GW 버전 미스매치 에서도 재시도 복구를 확인하였다.
* 기 배포된 1.1.x 버전에서 기인하는 제약 3건(KI-1~KI-3)은 수정이 불가하므로 대응 절차로 관리한다.
