== 목적 및 개요 (Purpose & Scope)

기존 NEUBOAT 버전 1(1.1.3, 1.1.5)에서 버전 2로 업데이트 시 마이그레이션 안정성을 확인한다. 또한 NEUBOAT 2.0.0 개선된 업데이트 기능의 적용 확인을 위해 2.0.0 → 2.0.1(가상 버전)의 업데이트를 검증한다.

* *테스트 범위*: NEUBOAT 전체 제품군 (Dock2, Dock2 Control, Navi, Navi Control, Full Assist, Full Control)
* *주요 검증*:
  - 1.1.3/1.1.5 → 2.0.0 마이그레이션 (DB 일관성)
  - 2.0.0 → 2.0.1 개선 업데이트 기능 적용 
  - ORU/MFD GW 업데이트 실패 후 재시도 시 버전 일치 여부

== 테스트 대상

_NEUBOAT 버전 업데이트의 안정성 및 호환성 검증을 위한 테스트 대상을 정의한다._

=== 테스트 대상 컴포넌트

- **ORU** (Object Recognition Unit) - 컴퓨팅 모듈
- **CCU** (Camera Control Unit) - SVM 카메라 컨트롤 모듈
- **MFD GW** (Multi-Function Display Gateway) - 유저 인터페이스 모듈
- **EIU** (Engine Gateway) - 엔진 인터페이스 모듈
- **FVM** (Front View Module) - 전방 인지 모듈

=== 주요 검증 항목

* 버전 업데이트 시 DB 마이그레이션 (1.1.3/1.1.5 → 2.0.0)
* 업데이트 기능 개선 (2.0.0 → 2.0.1)
* ORU/MFD GW 업데이트 실패 후 재시도 성공 여부

== 평가 항목

_테스트 결과를 정량적으로 평가하기 위한 지표를 정의한다._

=== 주요 검증 항목

* *정상 업그레이드*: 기존 배포 버전(1.1.3, 1.1.5) → 2.0.0 마이그레이션 검증
* *신규 기능 적용*: 2.0.0 → 2.0.1 업데이트에서 개선 기능 정상 적용 확인
* *실패 후 복구*: ORU/MFD GW 실패 시 재시도 성공 여부 검증
* *버전 적용 확인*: 업그레이드 대상 장비 및 컴포넌트의 목표 버전 적용 여부 확인
* *데이터 일관성*: 버전 업그레이드 후 기존 DB 정상 작동 여부

=== 버전 업데이트 및 모듈 실행 여부 확인

각 업데이트 후 다음을 확인:

. *기기 버전 확인*
  - ORU, CCU, MFD GW, FVM, Engine Gateway 모두 예상 버전으로 업데이트되었는지 검증

. *서비스 상태 확인*
  - 모듈 정상 실행 여부
