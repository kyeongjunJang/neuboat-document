**문서 버전**: 0.1  
**작성일**: 2026-07-21  
**대상 제품**: NEUBOAT 제품군 (Dock2, Dock2 Control, Navi, Navi Control, Full Assist, Full Control)  
**목적**: 버전 업데이트 안정성 검증 및 장애 복구 능력 확인

---

## 목적 및 개요

NEUBOAT 2.0.0 버전으로의 업데이트 프로세스를 검증하고, 레거시 버전(1.1.3, 1.1.5)에서의 마이그레이션 안정성을 확인한다. 또한 새로운 업데이트 기능의 개선사항이 정상 적용되는지 확인하기 위해 2.0.0 → 2.0.1(가상 버전)의 업데이트도 검증한다.

### 테스트 대상 컴포넌트

| 주요 장비 | 역할 |
|---------|------|
| **ORU** (Object Recognition Unit) | 컴퓨팅 시스템 |
| **MFD GW** (Multi-Function Display Gateway) | 디스플레이 게이트웨이 |
| **CCU** (Camera Control Unit) | 카메라 제어 (서브) |
| **EIU** (Engine Gateway) | 엔진 인터페이스 (서브) |
| **FVM** (Front View Module) | 전면 영상 모듈 (서브) |

## 실험 계획


### 로깅 방식 (테스트 3회)

각 업데이트 시나리오마다 **3회 반복** 수행:
1. **1차 테스트**: 정상 진행 경로 검증
2. **2차 테스트**: 일관성 및 안정성 재확인

로그 수집:
- [ ] 업데이트 진행 로그: 시간 및 상태 기록
- [ ] 에러 발생 시: 상세 내용 캡처

### 버전 호환성 확인 사항

다운그레이드 방식:
- **CCU**: SD 카드 슬롯을 통한 수동 다운그레이드 (통합 업데이트로 불가)
- **MFD GW**: SD 카드 슬롯을 통한 다운그레이드 가능

## 평가 항목

### 주요 검증 항목

- **정상 업그레이드**: 기존 배포 버전(1.1.3, 1.1.5) → 2.0.0 마이그레이션 검증
- **신규 기능 적용**: 2.0.0 → 2.0.1 업데이트에서 개선 기능 정상 적용 확인
- **실패 후 복구**: ORU/MFD GW 실패 시 재시도 성공 여부 검증
- **컴포넌트 호환성**: 각 컴포넌트 간 버전 조합 호환성 확인
- **데이터 일관성**: 버전 업그레이드 후 기존 DB 정상 작동 여부

### 확인 방법

각 업데이트 후 다음을 확인:

1. **컴포넌트 버전 확인**
   - ORU, CCU, MFD GW, FVM, Engine Gateway 모두 예상 버전으로 업데이트되었는지 검증

2. **서비스 상태 확인**
   - `tcli - tps` 모듈 정상 실행 여부

### 데이터베이스 및 파라미터 마이그레이션 검증

## 알려진 이슈 및 대응 방안(이거는 시험계획서 adoc에는 안들어갈거야 나중에 시험 보고서에서 같은 이슈 나타나면 적어두자.)

이 섹션은 시험 중 발생 가능한 문제들과 임시 조치 방법입니다. 현장에서 유사한 상황 발생 시 참고하세요.

### Issue #1: CCU Skip 처리
**현상**: 업데이트 중 CCU가 skip 처리되어 버전 유지  
**임시 대응**:
- [ ] 재시도 (1회)
- [ ] 재시도 (2회)
- [ ] CCU 물리적 전원 OFF → 5분 대기 → ON
- [ ] 재시도 후 버전 확인

### Issue #2: WiFi 다운로드 실패
**현상**: 업데이트 다운로드 중 실패 ("빨간색 바" 또는 무작위 진행률)  
**임시 대응**:
- [ ] WiFi 재접속
- [ ] MFD GW 재부팅
- [ ] 유선 네트워크로 변경 후 재시도

### Issue #3: 영상 스트림 미수신
**현상**: go2rtc에서 검은 화면 또는 프레임 드롭  
**원인**: NEUBOAT 2.0.0에서 영상 포맷 변경 → CCU 2.0.0 필수  
**임시 대응**:
- [ ] CCU 버전 확인 및 2.0.0 이상 업그레이드
- [ ] SVM 서비스 재시작
- [ ] RTSP 스트림 소스 재확인

### Issue #4: 네트워크 IP 변경
**현상**: NIC reset 후 IP 변경, SSH 접속 불가  
**임시 대응**:
- [ ] dmesg에서 "NIC reset" 확인
- [ ] 다른 IP 대역(172)으로 접속 시도
- [ ] `systemctl restart` 수행
- [ ] IP 재할당 확인

### Issue #5: 서비스 미실행
**현상**: 업데이트 완료 후 copilot.service 미시작  
**임시 대응**:
- [ ] ORU 추가 재부팅
- [ ] `systemctl status copilot` 확인
- [ ] `systemctl restart copilot` 수행

### Issue #6: FVM 버전 미업데이트
**현상**: Platform 업데이트는 완료되었으나 FVM만 버전 유지  
**임시 대응**:
- [ ] `journalctl -u fvm` 로그 확인
- [ ] FVM 수동 업데이트 시도
- [ ] FVM 서비스 재시작

### Issue #7: EIU DB 손상 (다운그레이드 시)
**현상**: MFD 1.1.4 + EIU 1.0.2.0 조합에서 Engine Index 손상  
**임시 대응**:
- [ ] EIU 다운그레이드 전 Engine Index 삭제
- [ ] EIU 다운그레이드 수행
- [ ] Engine Index 재설정
